Ready player one

Install the arcade

1. Connect

Attach a QwSTPad to Presto's Qw/ST connector. The games expect I2C 0 using GPIO 40 and 41.

2. Copy

Copy main.py, each game and any required game assets to the root of the board.

3. Play

Reset Presto, swipe the carousel and tap a title. In every game, - returns to the menu.

Full installation notes
